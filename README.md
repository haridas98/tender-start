# ТендерСтарт

MVP сервиса для поиска прибыльных закупок: вещество → производители →
потребители → экономика поставки → AI-подсказка.

Сейчас это рабочий фронтенд-прототип на демо-данных. Он показывает:

- каталог веществ;
- производителей и их условные мощности/цены;
- потребности покупателей;
- расчёт доставки, НДС, маржи и потенциальной прибыли;
- эвристический AI-разбор сделки;
- план подключения источников ЕИС, ЕГРЮЛ и ГИСП.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run build
```

## Важно

Данные в `src/data/demoMarket.ts` демонстрационные. Они нужны, чтобы показать
ценность продукта до подключения настоящих выгрузок.
