# Этапы сбора заводов РФ

## Массовый слой 2026-06-01

- Команда: `npm run collect:russia-plants -- --target=50 --max-pages=20 --concurrency=10`.
- Источники: `manufacturers.ru`, `FoodSuppliers`, `Fabricators`, архив `ГИСП/Apicrafter 2021`.
- Результат текущего прогона: 3845 lead-карточек, 70 из 89 регионов РФ имеют 50+ карточек.
- Не добиты до 50 по открытым источникам: ДНР, ЛНР, Запорожская область, Херсонская область, ЕАО, НАО, Магаданская область, Республика Алтай, Камчатский край, Республика Тыва, Чукотский АО, Ингушетия, Калмыкия, Северная Осетия - Алания, ЯНАО, Саха (Якутия), Чечня, Сахалинская область, ХМАО - Югра.
- Правило: не добавляем выдуманные заводы ради числа; недостающие регионы добираем через дополнительные региональные реестры, сайты администраций, ЕИС/ЭТП и сайты предприятий.

## Массовый слой СНГ 2026-06-01

- Команда: `npm run collect:cis-plants -- --target=50 --max-pages=12 --concurrency=5`.
- Источники: `manufacturers.ru/foreign-companies`, `Made in Turkmenistan`, локальный реестр тендерных площадок СНГ.
- Результат текущего прогона: 360 lead-карточек, 6 из 9 стран имеют 50+ карточек.
- Готовы по 50+: Казахстан, Беларусь, Узбекистан, Армения, Азербайджан, Туркменистан.
- Не добиты по открытым источникам: Кыргызстан 36/50, Таджикистан 8/50, Молдова 16/50.
- Тендерные площадки для ежедневного парсинга: goszakup.gov.kz, zakup.sk.kz, goszakupki.by, icetrade.by, xarid.uz, dxarid.uzex.uz, zakupki.gov.kg, gnumner.am, armeps.am, etender.gov.az, mtender.gov.md, achizitii.md, zakupki.gov.tj, exchange.gov.tm.

Цель: идти по регионам, добавляя заводы всех отраслей: продукция, сырье, оборудование, закупки, контакты, документы, логистика, источники и статус верификации.

## Правило карточки завода

- Юрлицо, бренд, ИНН при наличии.
- Адрес, город, регион, страна.
- Сайт, публичные телефоны, email, соцсети.
- Отдел закупок: только публичный контакт; если нет - отмечаем, что не найден.
- Продукция.
- Что закупает: сырье, упаковка, техника, оборудование, реагенты, логистика, сервис.
- Для презентационной карточки обязательно добавляем конкретные строки:
  - `productionItems` - точные наименования продукции, спецификация, объем/статус, документы, источник.
  - `demandItems` - точные закупочные позиции, спецификация, объем/статус, документы, источник.
- Документы: COA/паспорт качества, SDS/MSDS, сертификаты, ветдокументы, чертежи, ТЗ, договоры, температурный режим, промбезопасность.
- Источник и уровень доверия: verified / estimated / lead.
- Закупки делим на два слоя:
  - `подтверждено закупкой` - есть извещение/ЭТП/ТЗ/проект договора/протокол.
  - `профильная гипотеза` - вывод по отрасли и продукции, пока без тендерного документа.
- Фильтр проекта: исключаем алкоголь, мясо, рыбу, икру и связанные закупки/производства. Это не добавляем в видимую базу и не используем как лиды.
