# План: India → Russia Chemical Intelligence

## Цель

Сервис для входа в рынок индийской химии с экспортом в РФ: найти товар,
поставщика, российского покупателя, документы, маршрут, цену, риски и маржу.

## Первый рабочий срез

- Каталог химикатов: HS/ТН ВЭД, CAS, формула, применение.
- Индийские поставщики: компания, город/штат, продукты, MOQ, цена, документы.
- Российский спрос: компании, объёмы, целевая цена, источник потребности.
- Документы: SDS, COA, ISO, REACH, сертификаты, срок действия.
- Логистика: порт Индии → маршрут → РФ, стоимость, срок, риск.
- Сделка: EXW/FOB + фрахт + пошлина + НДС + маржа.
- AI-разбор: стоит ли заходить, что запросить, кому писать.

## Источники данных

- Indian Trade Analytics / Department of Commerce.
- Export Import Data Bank / TRADESTAT.
- CHEMEXCIL и CAPEXIL.
- ICEGATE / таможенные HS-данные Индии.
- ЕИС закупки РФ.
- ФНС ЕГРЮЛ.
- Росаккредитация.
- Ручное обогащение контактов и документов.

## Рост проекта

1. Сначала 10-20 химикатов и ручная верификация.
2. Потом полуавтоматический сбор поставщиков, документов и закупок.
3. Потом история цен, конкуренты, логистика, контакты.
4. Потом сценарный движок: пошлины, санкции, закрытие маршрутов, дефицит.
5. Дальше — экономическая разведка уровня “кто выиграет/проиграет от события”.

## Что делаем сейчас

Переделываем MVP из “агрегатора тендеров” в личный cockpit:

- слева выбор химиката из Индии;
- в центре поставщики, спрос РФ, документы, маршруты;
- справа расчёт сделки и AI-рекомендация.

## Ежедневный сбор российских заказчиков

- Основной источник: ЕИС / zakupki.gov.ru, поиск по химическим названиям,
  формулам, HS/ТН ВЭД и синонимам.
- Выходной файл: `src/data/russianDemandFeed.json`.
- Скрипт: `npm run collect:russia-demand`.
- Расписание: GitHub Actions workflow `.github/workflows/daily-russian-demand.yml`,
  один раз в день.
- Пока контакты закупщиков помечаются как “нужно обогатить”; следующий шаг —
  вытаскивать их из карточек закупки и документов.
